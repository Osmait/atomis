Where a run's time goes

Wall-clock timelines from ATOMIS_TRACE: the server's spans for each run joined with the client's own timestamps, on one clock. Every millisecond between pressing Run and seeing the result is assigned to a segment, so waiting shows up as well as work.

Median run, by segment

Processes: compilers, linkers, the program, instrumenter CLIs, workers and Zig's compile servers. Server: the server's own time inside a phase, between those. Network: client to server and back over the WebSocket.
